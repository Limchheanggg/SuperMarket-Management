<h2>📚 About This Project</h2>

<p>
This repository contains a full-stack <b>SuperMarket Management System</b> developed as a university project for learning modern web development, backend architecture, and database management.
</p>

<p>
The project includes both customer-side features and an admin dashboard system for managing supermarket operations efficiently.
</p>

<h3>🎯 Main Goals</h3>

<ul>
  <li>Learn full-stack development workflow</li>
  <li>Understand frontend & backend integration</li>
  <li>Practice REST API development</li>
  <li>Improve database design skills</li>
  <li>Build a real-world management system</li>
</ul>

<hr>

<h2>⚙️ Technologies Used</h2>

<h3>🎨 Frontend</h3>

<ul>
  <li>React.js</li>
  <li>Vite</li>
  <li>Tailwind CSS</li>
  <li>Axios</li>
  <li>React Router DOM</li>
  <li>Radix UI</li>
  <li>Lucide React</li>
</ul>

<h3>🧠 Backend</h3>

<ul>
  <li>FastAPI</li>
  <li>SQLAlchemy ORM</li>
  <li>REST API Architecture</li>
  <li>Python</li>
</ul>

<h3>🗄️ Database</h3>

<ul>
  <li>MySQL</li>
  <li>MySQL Workbench</li>
</ul>

<hr>

<h2>🔄 System Workflow</h2>

<pre>
React Frontend
      ↓
Axios HTTP Requests
      ↓
FastAPI Backend
      ↓
SQLAlchemy ORM
      ↓
MySQL Database
</pre>
